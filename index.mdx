**ORION is a pocket satellite you hold in your hand.** A 280 × 240 colour touch instrument panel,
motion sensing, audio, and an operating environment built around the idea that every use is a
mission. It is a project of ANX Labs, and it is under active development.

Three things make up the platform:

## MissionOS

A mission-control interface for a pocket satellite. Instruments read like telemetry panels, logging
sessions have a brief and a debrief, and the device can act as either the satellite or the ground
station.

The design language is called **Ground Control**: dark, instrument-grade, calm. Telemetry numerals
in mono, thin rules, and colour used as signal rather than decoration. One glance answers *what is
the value, and is it OK*.

## Built for exploration

Seven categories of instruments and tools, plus a tab for the apps you install yourself.

|---|---|

| **Play** | Snake, Breakout, Dice & Spinner, Reaction Timer |
| **System** | Settings, Files, Power, Alerts, Charge face, System Update |

## Build your own

The User App Platform runs WebAssembly apps in a sandbox alongside MissionOS. You write C, the SDK
compiles and packages it, and ORION validates it twice before anything runs.

<CodeGroup>

```c sdk/examples/tap_counter/src/main.c (abridged)
#include <orion/orion.h>

static int32_t count;

void orion_app_on_enter(void)
{
    int32_t stored;
    if (orion_storage_read_str("tap_count", &stored, sizeof stored) == (int32_t)sizeof stored) {
        count = stored;
    }
}

void orion_app_update(void)
{
    orion_touch_event_t touch;
    if (orion_touch_read(&touch) != ORION_OK || touch.gesture != ORION_GESTURE_TAP) {
        return;
    }
    ++count;
    orion_storage_write_str("tap_count", &count, sizeof count);
    orion_request_redraw();
}

void orion_app_draw(void)
{
    char line[24];
    int32_t n = orion_copy_str(line, "Taps: ");
    n += orion_format_int(line + n, count);
    orion_display_text(24, 96, line, n, ORION_COLOR_TEXT, ORION_TEXT_HERO_COMPACT);
}
```

```bash Build and install
sdk/bin/orion build my_counter
sdk/bin/orion install my_counter/build/MyCounter-1.0.0.orionapp \
  --port /dev/cu.usbmodem1101 --launch
```

</CodeGroup>

The app appears in the launcher's **User Apps** tab. Swipe from the left edge to leave it.

## The platform, at a glance

| | |
|---|---|
| **Interface** | 280 × 240 landscape colour touch panel, seven launcher categories, 47 specified screens |
| **Runtime** | WAMR 2.4.5 fast interpreter, 4 MiB PSRAM arena, ~252 Hz with an app running |
| **App contract** | ABI 1.0, frozen — 5 capability modules, 13 functions, drift-checked against the firmware |
| **Containment** | Per-callback instruction limit and wall-clock budget; a failing app is stopped, MissionOS continues |
| **Packaging** | `.orionapp` — manifest, icon, WebAssembly module, SHA-256 digest |
| **Storage** | A private key/value store per app, on its own flash partition, kept across restarts |
